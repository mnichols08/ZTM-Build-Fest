# v1.0 Reality Check — End-User Experience Assessment

> **Status: NOT STARTED.** This is the template for issue #163. Fill it in as
> you test; leave anything you didn't do as **NOT RUN**. Write what you saw,
> not what the code is supposed to do. Use only synthetic household data.

Severity: **P0** can't safely finish an essential task · **P1** a main
workflow is blocked or seriously confusing · **P2** recurring friction ·
**P3** minor polish · **P4** idea. Every P0/P1 becomes an issue labelled
`v1.0-blocker`, linked in the friction inventory below; P2 and lower become
issues for after v1.0.

Confidence: **Observed** (you saw it) · **Evidence-supported** (screenshot or
log, not fully re-run) · **Hypothesis** (a guess that needs checking).
